# Start Here

## What this project is

This website is a public-information learning resource. It explains EI topics in plain language using publicly available references.

## What this project is not

- Not legal advice
- Not case strategy
- Not an official government publication
- Not a substitute for official guidance or professional advice

## How pages are structured

Each topic page is designed to grow with a consistent structure:

- Overview
- Why EI cares about this issue
- High-level decision flow
- Official source links
- Glossary terms
- Related topics

## Suggested reading order

1. [What EI Is](topics/what-ei-is.md)
2. [What EI Cares About and Why](topics/what-ei-cares-about.md)
3. Topic-specific pages (job separation, availability, training, etc.)
4. [Reconsideration](process/reconsideration.md) and [Appeals / Tribunal](process/appeals-tribunal.md)
5. [Official Sources](reference/official-sources.md)
