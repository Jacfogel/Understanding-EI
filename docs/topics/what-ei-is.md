# What EI Is

## Overview

Employment Insurance (EI) is a federal program with rules set through public laws, regulations, and policy materials.

## Why EI cares about this issue

Understanding program purpose helps explain why EI asks certain questions during claims and reviews.

## High-level decision flow

1. Is the claim type identified?
2. Are basic qualifying conditions met?
3. Are there factors that affect entitlement?
